# PCPartPicker links

PCPartPicker does not show prices in tenge. I used it only to check that the parts are compatible and that the power supply is enough.

Parts of all four builds: AMD Ryzen 5 7600X, MSI PRO B650M-P, Kingston NV3 1 TB, MSI MAG A650BN, an ID-Cooling SE-214-XT Basic (or a similar AM5 cooler) and an Ocypus Gamma C50 (or a similar micro-ATX case). Memory: Kingston Fury Beast DDR5-5200 2x8 GB (accountant, sales) or a DDR5-6000 2x16 GB kit (web developer, designer). The designer build also has a Gainward RTX 4060 Ti Pegasus 8 GB. 

- Build 1 - accountant: https://pcpartpicker.com/list/sCbtNp
- Build 2 - sales: https://pcpartpicker.com/list/sCbtNp (the same parts as the accountant, so one list is used for both builds)
- Build 3 - web developer: https://pcpartpicker.com/list/HXPxV4
- Build 4 - designer: https://pcpartpicker.com/list/JV7Y2k

Result: for all three lists PCPartPicker showed no incompatibility warnings. It only showed its general note that some physical constraints, for example RAM clearance with CPU coolers, are not checked. I checked the cooler myself: the ID-Cooling SE-214-XT Basic is about 150 mm high and the Ocypus Gamma C50 case allows coolers up to 160 mm.

All internal parts from budget.csv were found on PCPartPicker, none was replaced. Monitors, keyboards and operating systems are not in the lists, because they do not affect the compatibility of the parts.
